# Report outline (A4 team + B5 individual sections)

1. Title page, certificate, acknowledgement
2. Abstract
3. Introduction: problem with paper feedback, objectives, scope
4. System analysis: existing system, proposed system, feasibility
5. Requirements: functional, non-functional, hardware/software (Node.js, SQLite, VS Code, browser)
6. Design: architecture diagram (Browser -> api.js -> Express -> SQLite), use-case diagram, ER diagram (from `server/schema.sql`), data dictionary, page flow
7. Implementation: technologies, module-wise description (**one subsection per member, with screenshots, key code, and validations**)
8. Responsive design and accessibility: techniques used, screenshots at 3 widths, Lighthouse score
9. Security and privacy: hashing, role checks, anonymity design
10. Testing: test cases table (input, expected, actual, pass/fail)
11. Conclusion and future scope (email notifications, semester-wise trends, PDF reports)
12. References, appendix (team contribution table)
